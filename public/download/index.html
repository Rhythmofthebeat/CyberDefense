Quick Start

1

Deploy the Central Server

Run the Docker image on any internet-accessible server. Note the API key printed on startup.

docker run -d -p 4001:4001 -v cdc-data:/app/data rhythmbazari/cyber-defense-server:latest
2

Install the Agent on Each Device

Download and run the installer for your OS, entering your server URL and API key when prompted.

# macOS/Linux one-liner:
curl -fsSL https://cyberdefense.example.com/install.sh | sudo bash -s -- \
  --server http://YOUR_SERVER:4001 --key YOUR_API_KEY
3

Open the Dashboard

Navigate to your server URL in any browser. All connected devices appear automatically.

4

Install the Browser Extension (Optional)

Get a live badge showing fleet alert level in Chrome or Edge without opening the dashboard.
